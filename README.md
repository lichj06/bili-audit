# bili-audit

**B 站互动数据形态观察器** —— 用公开接口建立「正常互动分布」的基线，并测量两种相反的数据形态：

```
注水（假互动）  分布过于【规则/突变】：点赞率异常高而投币比异常低、评论高度模板化
问号（真共鸣）  分布有【结构】：短促、密集、情绪集中 —— 用「问号指数」量化
```

**两者是同一个问题的两面：这批互动数据是「真的吗」「是什么形状」。**

---

## ⚠️ 先说清楚这个项目是什么、不是什么

**它是什么：**
- 一套用**公开接口**（无需登录）采集 B 站视频统计与评论文本的工具
- 一个**正常互动比基线**（点赞/播放、投币/点赞、收藏/点赞、评论/播放 的中位数与分布）
- 一个「数值偏离群体分布程度」的计算器（稳健 z 分数，中位数 + MAD）
- 一个「问号指数」——评论中含 `?`/`？` 的比例，用于量化"预期违背型共鸣"

**它不是什么：**
- ❌ **不是刷量工具**，也不提供任何获取虚假互动的方法
- ❌ **不判定任何视频「注水了」** —— 只报告指标偏离程度，不做指控
- ❌ 不是全站普查 —— 样本来自热门榜，是抽样

**为什么不做「判定」：**

偏离 ≠ 注水。真实爆款、分区差异、官方推广、活动运营都会造成同样的偏离。
一份把"指标异常"直接等同于"刷量"的报告，等于在制造冤案。

---

## 一个必须讲明的样本约束

```
样本来自【热门榜】= 平台推荐位
     ↓
刷量视频通常上不了热榜
     ↓
所以本批样本里【本来就抓不到注水】
```

**这不是缺陷，是设计**：本项目建立的是**正常分布基线**。
有了基线，任何视频都可以拿来比 —— **基线才是可复用的产出。**

## 数据来源（全部公开，无需登录）

| 接口 | 用途 | 实测状态 |
|---|---|---|
| `x/web-interface/view?bvid=` | 视频信息 + stat（播放/点赞/投币/收藏/分享/评论/弹幕） | ✅ 可用 |
| `x/web-interface/popular` | 热门榜（批量取视频） | ✅ 可用 |
| `x/v2/reply/main?type=1&oid=` | 评论（JSON，每页 20 条） | ✅ 可用 |
| ~~弹幕~~ | ~~弹幕文本~~ | ❌ **不可用** —— 需登录 + 签名；旧 XML 端点只返回头部 |

> **注**：旧端点 `x/v2/reply` 只返回 3 条，`x/v2/reply/main` 返回满 20 条 —— 这是实测出来的差异。

## 两类指标怎么算

### A. 互动比（注水检测的输入）

```
点赞率   = like / view
投币比   = coin / like      ← 关键：投币成本远高于点赞
收藏比   = favorite / like
分享率   = share / view
评论率   = reply / view
弹幕率   = danmaku / view
```

**逻辑**：刷播放和刷赞便宜，刷投币/收藏贵。
**若某个视频的点赞率显著高于群体、而投币比显著低于群体 → 值得核对**（不是定罪）。

### B. 评论文本特征

```
完全重复率      1 − 去重后条数 / 总条数
前 8 字重复率   1 − 去重后前缀数 / 总条数   ← 水军模板的典型特征
用户集中度      同一用户占比
平均等级        评论者账号等级均值
```

### C. 问号指数

```
问号指数       含 ? 或 ？ 的评论占比
三重问号率     含 ??? 或 ？？？ 的评论占比
每千字问号数   总问号数 / 总字数 × 1000
```

**为什么用问号**：`？？？` 是**预期违背**的直接标记 —— 观众被内容震到、看不懂、或发现反转时才会打出来。
它同时触发**弹幕、评论、完播、二刷**，是四合一的高价值互动信号。

### 偏离度怎么算

用**稳健 z 分数**：`|x − median| / (1.4826 × MAD)`，阈值取 3.0。

比普通标准差稳健 —— 少数极端值不会污染阈值。

## 用法

```bash
# ① 采集（默认限速 0.6–1.3 秒/请求，避免给 B 站造成负担）
python3 bili/collect.py --pages 3 --comment-pages 4

# ② 分析
python3 analysis/analyze.py
```

产出：
```
data/videos.jsonl     每个视频的 stat 全字段
data/comments.jsonl   每条评论的文本/点赞数/时间/用户哈希
data/analysis.json    逐视频的指标与偏离度
report/数据观察.md     可读报告
```

## 立场与边界

```
· 只用公开接口，不登录、不抓取需要授权的数据
· 不做任何刷量操作，也不提供获取虚假互动的方法
· 不点名指控任何账号或 UP 主 —— 只报告指标分布
· 用户 id 只存 SHA1 前 12 位，不保存原始身份
· 限速请求，不给平台造成负担
· 欢迎指出方法错误 —— 尤其是"偏离"与"注水"之间被我混淆的地方
```
